Analytics setup and verification
===============================

The sitemap uses https://fundededucationfutures.com, matching the existing sharing page. Confirm this is the canonical production domain before deployment.

Google Analytics 4 is implemented but cannot send real data until the website owner supplies a public measurement ID. Set VITE_GA_MEASUREMENT_ID=G-YOURMEASUREMENTID in the hosting build environment, then build the site. Do not put account passwords or API secrets in VITE_ variables: these variables are public browser configuration.

In the GA4 web data stream, turn Enhanced Measurement off, including automatic history page views and form interactions. The app sends its own page_view events and form submission events so SPA navigation is counted once. Enable no extra custom dimensions unless needed.

Tracking starts only after Accept Cookies. Reject leaves the Google tag unloaded. Visitors can reopen Cookie Preferences on the Privacy Policy page. Older cookieDismissed values do not count as analytics consent.

Collected events:
- page_view: pathname-only page URL, title, preceding page/referrer; no query parameters or fragments.
- button_click and link_click: short action label, page pathname, sanitized link destination. Contact labels are masked; form values are never read.
- newsletter_submit, volunteer_submit, donation_confirmation_submit: a submitted_unverified status. These describe a browser submission, not verified backend acceptance or a confirmed payment. Do not label donation_confirmation_submit as revenue/purchase.

GA4 supplies acquisition, referral, geographic and device reports. After an approved production deployment, accept cookies and navigate between pages; check GA4 Realtime and DebugView for one page_view per route plus interactions. Test rejected consent in a fresh browser profile and check that no Google tag is requested. Confirm successful form receipt separately in the Apps Script/Sheets backend: its existing no-cors requests return opaque responses that the browser cannot validate.

Sitemap is regenerated by npm run build. All public routes are included except /thank-you, which also receives noindex metadata. robots.txt points to the sitemap. After approved deployment, verify that /sitemap.xml serves XML rather than the SPA HTML fallback; submit it to the owner's Google Search Console property. A sitemap helps discovery but cannot guarantee indexing.

Repeat local audit
------------------
Run npm run lint and npm run build. Start npm run dev. With Playwright and Chromium installed, run node tests/audit.mjs (or specify AUDIT_PLAYWRIGHT_MODULE and PLAYWRIGHT_BROWSERS_PATH for a temporary installation). The audit intercepts Apps Script submissions and does not create real registrations or donation records.
